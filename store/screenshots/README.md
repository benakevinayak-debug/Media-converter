# Desktop 1.3 interface previews

These PNGs show the actual dark purple desktop interface, current-queue states,
credits, and light mode. They were captured in Chromium using a local test bridge.
They are UI previews, not proof of native Windows installation or certification.

Recapture the installed Windows release before publishing a Store listing.
Desktop Store screenshots must be at least 1366 × 768; these design-preview
captures are 1360 × 860 and should not be submitted unchanged.
