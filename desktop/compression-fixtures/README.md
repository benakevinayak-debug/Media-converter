# Compression verification fixtures

Procedural still-image fixtures are generated by `scripts/create-compression-fixtures.cjs`. They include Display-P3 ICC profiles, EXIF orientation 6, alpha gradients, and deliberately low compression. The APNG has two different frames with 70/130 ms delays and three loops. The animated WebP has two different frames with the same timing and loop count. `animated.avif` is a three-frame AV1/AVIF animation generated locally with the bundled FFmpeg.

`animated.jxl` is an unmodified copy of `jxl/blending/cropped_traffic_light.jxl` from https://github.com/libjxl/testdata, by the libjxl/testdata contributors, under CC BY 4.0. The license is included in `licenses/libjxl-testdata-CC-BY-4.0.txt`. It has four animation keyframes. This fixture is used for testing; no endorsement is implied.

`alpha-metadata.jxl` contains a losslessly encoded alpha gradient and repetitive XML metadata. It demonstrates genuine lossless metadata-container compression rather than a size estimate. JXL image codestreams remain byte-for-byte unchanged. `still.avif` includes trailing `free` padding to verify container optimization without shifting image offsets.

`broken.png` is intentionally malformed. It must fail without stopping the next image.
